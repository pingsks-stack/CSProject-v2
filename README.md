# CS Project — ระบบติดตามโครงงาน มหาวิทยาลัยพะเยา

เว็บสำหรับนิสิต อาจารย์ และผู้ดูแลระบบ ใช้สร้างโครงงาน เชิญอาจารย์ที่ปรึกษา/กรรมการ ส่งเอกสารรายบทพร้อมความเห็นอาจารย์
พิจารณาผ่าน 3/3 พิมพ์แบบฟอร์มยืนยัน และเก็บเป็นคลังโครงงาน/ซอร์สโค้ดสำหรับรุ่นต่อไป

| ส่วน | เทคโนโลยี |
|---|---|
| หน้าเว็บ (`client/`) | React 19 + Vite + TypeScript + Tailwind CSS 4, React Router, TanStack Query |
| API (`server/`) | Node.js + Express 5 + TypeScript, Mongoose |
| ฐานข้อมูล | MongoDB |

> เวอร์ชัน 2 (repo นี้) เขียนใหม่ทั้งหมดแทนระบบเดิม (ASP.NET Web Forms) ซึ่งอยู่ใน repo [CSProject](https://github.com/pingsks-stack/CSProject)
> วิธีติดตั้งบนเซิร์ฟเวอร์ดูที่ [docs/INSTALL.md](docs/INSTALL.md)

## โครงสร้างโฟลเดอร์

```
CSProject/
├─ client/                 หน้าเว็บ React
│  └─ src/
│     ├─ pages/            หน้าต่าง ๆ (admin/ = หน้าผู้ดูแลระบบ)
│     ├─ components/       Layout เมนู ปุ่ม กล่องยืนยัน กราฟ ฯลฯ ที่ใช้ร่วมกัน
│     └─ lib/              เรียก API, ระบบล็อกอิน, type ของข้อมูล, จัดรูปแบบวันที่ไทย
├─ server/                 API
│  ├─ src/
│  │  ├─ routes/           API แต่ละกลุ่ม (auth, projects, requests, content, chat, dashboard, admin)
│  │  ├─ models/           โครงสร้างข้อมูล MongoDB
│  │  ├─ lib/              สิทธิ์การเข้าถึง, รหัสผ่าน, อัปโหลดไฟล์, แจ้งเตือน
│  │  └─ seed.ts           ข้อมูลตัวอย่าง
│  ├─ uploads/             ไฟล์ที่ผู้ใช้อัปโหลด (ไม่เก็บใน git)
│  └─ data/                MongoDB ของเครื่องพัฒนา (ไม่เก็บใน git)
├─ docs/                   คู่มือติดตั้ง
└─ package.json            สั่งรัน client + server พร้อมกัน
```

## วิธีรันบนเครื่อง

ต้องมี **Node.js 22** ขึ้นไป ไม่ต้องติดตั้ง MongoDB เอง

```
npm install
npm run dev
```

เปิด http://localhost:5173

- ครั้งแรก server จะดาวน์โหลด MongoDB (~780 MB) มาเก็บที่ `~/.cache/mongodb-binaries` ให้อัตโนมัติ (ใช้เวลาสักครู่) แล้วเก็บข้อมูลไว้ที่ `server/data/`
- ถ้าฐานข้อมูลว่าง จะใส่ข้อมูลตัวอย่างให้เอง
- ล้างข้อมูลแล้วเริ่มใหม่: ปิด `npm run dev` ก่อน แล้วสั่ง `npm run seed`
- ถ้ามี MongoDB อยู่แล้ว ให้คัดลอก `server/.env.example` เป็น `server/.env` แล้วตั้ง `MONGODB_URI`
- อีเมลที่ระบบส่ง (แจ้งเตือน, ลิงก์ลืมรหัสผ่าน) บนเครื่องพัฒนาจะถูกบันทึกเป็นไฟล์ `.html` ใน `server/data/mail/` แทนการส่งจริง

### คำสั่งอื่น

| คำสั่ง | ทำอะไร |
|---|---|
| `npm run typecheck` | ตรวจ TypeScript ทั้ง client และ server |
| `npm test` | ชุดทดสอบ API (ใช้ MongoDB ชั่วคราวในหน่วยความจำ ไม่แตะข้อมูลจริง) — GitHub Actions รันให้ทุกครั้งที่ push |
| `npm run build` | build server (`server/dist`) และ client (`client/dist`) |
| `npm start` | รัน server ที่ build แล้ว (เสิร์ฟหน้าเว็บด้วย) |
| `npm run seed` | ล้างฐานข้อมูลเครื่องพัฒนาแล้วใส่ข้อมูลตัวอย่างใหม่ (ปิด `npm run dev` ก่อน) |
| `npm run create-admin` | สร้างบัญชีผู้ดูแลระบบ / รีเซ็ตรหัสผ่านแอดมิน |
| `npm run backup` / `npm run restore -- <ชุด> --yes` | สำรอง / กู้คืนฐานข้อมูลและไฟล์อัปโหลด |

## คลังโครงงานสาธารณะ (สำหรับรุ่นน้อง)

เปิด `/showcase` (มีลิงก์ที่หน้าเข้าสู่ระบบและหน้าคลังโครงงาน) **ไม่ต้องล็อกอิน**
แสดงเฉพาะโครงงานที่ผ่าน 3/3 แล้ว ค้นหาตามชื่อโครงงาน/ชื่อรุ่นพี่/อาจารย์ กรองตามประเภทและปีการศึกษาได้

- ทุกคนเห็น: ชื่อโครงงาน บทคัดย่อ คำสำคัญ ภาพหน้าจอ ลิงก์เดโม/วิดีโอ ผู้จัดทำ อาจารย์ที่ปรึกษา/กรรมการ ซอร์สโค้ด และงานบน GitHub (ไม่แสดงอีเมล เบอร์โทร รหัสนิสิต)
- นิสิตกรอกบทคัดย่อ คำสำคัญ ลิงก์ และอัปโหลดภาพหน้าจอ (ไม่เกิน 6 รูป รูปแรกเป็นภาพปก) ได้ที่หน้าโครงงาน → "ข้อมูลคลังโครงงาน"
- ต้องเข้าสู่ระบบก่อน: เปิดอ่านเล่มสมบูรณ์/เอกสารรายบท (PDF เปิดอ่านในเว็บได้เลย) และดาวน์โหลดไฟล์ รุ่นน้องสมัครสมาชิกเองได้ด้วยรหัสนิสิต
- แต่ละโครงงานมีลิงก์ของตัวเอง (`/showcase/<id>`) คัดลอกไปแชร์ได้

## อัปเดตงานผ่าน GitHub

นิสิตเชื่อม GitHub repository (แบบ public) ได้ที่หน้าจัดการโครงงาน → แผง "GitHub"

- ระบบดึงคำอธิบาย ภาษาที่ใช้ commit ล่าสุด และ README มาแสดงในหน้าโครงงานและคลังโครงงานสาธารณะ
- อาจารย์ในโครงงานได้รับแจ้งเตือนเมื่อมี commit ใหม่ และเห็นในประวัติของโครงงาน
- "นำเข้าไฟล์โค้ด" เลือกไฟล์จาก repository มาไว้ในคลังซอร์สโค้ด ไฟล์เหล่านี้อัปเดตตาม GitHub ทุกครั้งที่ซิงค์ (แก้ไขใน repository แทนการแก้ในเว็บ)
- ระบบซิงค์เมื่อเปิดหน้าโครงงานแล้วข้อมูลเก่ากว่า 30 นาที หรือกด "อัปเดตตอนนี้"

ตั้งค่าเพิ่มใน `server/.env` (ไม่บังคับ):

| ค่า | ใช้ทำอะไร |
|---|---|
| `GITHUB_TOKEN` | personal access token ของ GitHub (แบบ fine-grained อ่าน public repositories อย่างเดียวพอ) เพิ่มโควตาจาก 60 เป็น 5,000 ครั้ง/ชม. ควรตั้งเมื่อมีหลายโครงงาน |
| `GITHUB_WEBHOOK_SECRET` | เปิดใช้ webhook ให้งานอัปเดตทันทีที่ push (เซิร์ฟเวอร์ต้องเข้าถึงได้จากอินเทอร์เน็ต) |

วิธีตั้ง webhook (นิสิตทำใน repository ของตัวเอง): Settings → Webhooks → Add webhook
- Payload URL: `https://<โดเมนของระบบ>/api/github/webhook`
- Content type: `application/json`
- Secret: ค่าเดียวกับ `GITHUB_WEBHOOK_SECRET` (ขอจากผู้ดูแลระบบ)
- เลือก "Just the push event"

## อีเมลและการแจ้งเตือน

- การแจ้งเตือนสำคัญ (คำเชิญอาจารย์ ผลอนุมัติคำขอ ผลตรวจเอกสาร ผลพิจารณา ความเห็นอาจารย์) แสดงที่กระดิ่งและส่งอีเมลด้วย ผู้ใช้ปิดรับอีเมลได้ที่หน้าโปรไฟล์
- เตือนกำหนดส่งอัตโนมัติ: นิสิตที่ยังไม่ส่งบทนั้นจะได้รับแจ้งเมื่อเหลือ 3 วัน, 1 วัน และหลังเลยกำหนด 1 วัน
- ลืมรหัสผ่าน: หน้าเข้าสู่ระบบ → "ลืมรหัสผ่าน?" ระบบส่งลิงก์ตั้งรหัสใหม่ (ใช้ได้ 1 ชั่วโมง ครั้งเดียว) เปลี่ยนรหัสแล้วออกจากระบบทุกเครื่อง
- ตั้งค่า SMTP ดูที่ [docs/INSTALL.md](docs/INSTALL.md#9-ตั้งค่าการส่งอีเมล)

## สิ่งที่เปลี่ยนจากระบบเดิม

ฟีเจอร์ครบตามระบบเดิม และแก้ปัญหาที่พบระหว่างย้ายระบบ:

- **สิทธิ์ตรวจที่ server ทุกคำสั่ง** เดิมหลายอย่างตรวจแค่ในเบราว์เซอร์ เช่น สิทธิ์อาจารย์ที่ปรึกษา (ดูจาก `?uRole=` ใน URL) และอาจารย์กดผ่านแทนกันได้
- **ผลพิจารณาคำนวณจากผลของอาจารย์แต่ละท่าน** (ผ่านครบ 3 ท่าน = ผ่าน, มีท่านใดไม่ผ่าน = ไม่ผ่าน) แทนตัวนับแบบข้อความ ลบอาจารย์แล้วผลคำนวณใหม่ให้ถูกต้อง
- **อาจารย์ทั้งที่ปรึกษาและกรรมการต้องตอบรับคำเชิญ** (เดิมกรรมการถูกเพิ่มโดยไม่ต้องยินยอม) และนับคำเชิญที่รออยู่ด้วย จึงไม่เกิดที่ปรึกษา 2 ท่านหรืออาจารย์เกิน 3 ท่าน
- นิสิตมีได้ 1 โครงงานจริง (เดิมแค่แสดงข้อความเตือนแต่ยังบันทึก) และเพิ่มคู่โปรเจคได้เฉพาะนิสิตที่ยังไม่มีโครงงาน
- ไฟล์ทุกไฟล์เก็บแยกตามโครงงานและดาวน์โหลดผ่าน API ที่ตรวจสิทธิ์ (เดิมไฟล์โครงงานอยู่โฟลเดอร์สาธารณะรวมกัน ชื่อซ้ำทับกัน)
- แบบฟอร์มยืนยันโครงงานพิมพ์จากหน้าเว็บ (บันทึกเป็น PDF ได้) ใช้ปีการศึกษาของโครงงาน และชื่อประธานหลักสูตรตั้งได้ที่หน้า "ตั้งค่าแบบฟอร์ม" (เดิมเขียนตายตัว 2566)
- นิสิตได้รับแจ้งเตือนผลคำขอและผลพิจารณา, ความเห็นรายบทของอาจารย์ 1 ท่านต่อ 1 เวอร์ชัน (ส่งซ้ำ = แก้ไข)
- ข้อมูลติดต่อ (อีเมล/เบอร์โทร) ของสมาชิกแสดงเฉพาะคนในโครงงานและแอดมิน
- เพิ่มใหม่: คลังโครงงานสาธารณะสำหรับรุ่นน้อง และการอัปเดตงานผ่าน GitHub (ดูหัวข้อด้านบน)
- หน้าเดิมที่เป็นช่องโหว่ (index.aspx, user_infor.aspx, pushfriend.aspx, Edit.aspx) ไม่ได้ย้ายมา
